# 原版世界书：Kin 入世前的游戏常识

首版只面向**Minecraft Java 原版生存玩法**。Fabric 客户端模组用于接入 Kin 的感知与控制，不代表首版支持模组物品、生物、配方或改变玩法的扩展；模组支持列入 future。具体 Java 游戏版本在原型前固定，世界书与客户端版本必须一致。

世界书让 Kin 即使使用训练知识较旧的模型，也能理解自己进入的游戏：普通方块/物品/生物是什么，基本生存与进度如何展开，当前原版版本新增或变更了什么。它是**公共游戏机制知识**，不是这张服务器地图的当前状态，不包含世界 seed、未观察矿物坐标、墙后玩家或未经访问的箱子内容。

通用基础与版本术语是公共底座；各 Kin 开局通过[领域知识掌握多边形](knowledge-profile.md)自定义或生成进阶专题的覆盖与深度。高知识方向需要对应的版本资料和可核查节点，不能靠调高分数让模型假装专家；低知识方向也不抹去 LLM 的训练知识，突发高级想法可作为未经证实的猜想去试验。

| 知识层 | 预置范围 | 使用方式 |
| --- | --- | --- |
| 通用生存基础 | 血量、饥饿、昼夜、工具、采集、合成、熔炼、战斗、种植、维度与基本发展路线 | 短而稳定的索引；按任务读取具体主题 |
| 当前版本覆盖 | 本版本加入/变更的实体、方块、物品、配方和与生存有关的机制 | 与游戏版本绑定；遇到名称/物品 ID 或规划任务时检索 |
| 角色进阶知识树 | 根据每个 Kin 的开局知识画像配备典型建筑、生存策略、红石和进度计划等专题，标明覆盖深度 | 仅在对应目标出现时读取；是已知资料而非已掌握施工 |
| Kin 的亲历与外部查询 | 自己试过的结果，以及后来查询到的版本匹配公开资料 | 与预置知识分开存储；矛盾时标记并复查 |

不把“稍微全一点”理解为每次 LLM 调用都塞一本百科。使用按主题/物品 ID、别名和版本检索，返回少量适用条目及其出处；需要查复杂步骤时再展开，紧急反射完全不等待世界书。条目建议保留版本范围、来源、核查日期、条目类型、基本用法、前提条件、常见错误和指向详细资料的链接。预置内容应整理为原创的简要事实与指引，不照搬完整攻略。

## 版本校验与更新

候选首版以 [Minecraft Java 1.21.4 官方更新说明（2024-12-02）](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-21-4)等第一手版本资料建立变更清单，而不是自动取官网最新版本条目；详细来源层级、知识对象和验收见[世界书实施契约](world-guide-implementation.md)。再核对游戏内真实内容、公开可见的配方与操作结果。官方更新说明能指出新增机制，但不一定覆盖所有施工步骤；具体教程需查对应版本、来源和条件。客户端能识别某个物品 ID 或名称不意味着模型已经知道它的作用，更不证明该物品出现在 Kin 观察不到的地点。

启动时检查世界书声明的版本与实际客户端/服务器兼容版本。若不匹配，不用旧知识装作熟悉；先标记知识不确定，再按[外部工具](external-tools.md)查对应机制。原版数据包/服务器规则若改变原版行为，首版仍只依据真人正常能知道的公开规则和 Kin 的试验结果，不读取服务器私有配置。每次升级版本应重建变更索引，并用旧版本错误条目和新物品用法回归验证。

## 什么情况自己查资料

- 观察到的方块/物品/生物在所选版本索引里缺失，或知道名字却不理解用途。
- 计划要求具体机制，但只有概念性的常识，例如答应和朋友建刷怪塔却不知当前版本的有效施工条件。
- 世界书条目与实际游戏结果或可靠的新版本资料冲突。
- 查询到的信息不够可靠、适用版本不确定，Kin 可以先承认不知道、尝试安全的小实验或向玩家询问。

查到的网页知识先放在带来源、版本与获取时间的外部知识层。角色可说“我查了一种方案，但还没在我们这服试过”；只有游戏内验证过的经验才能成为自己的稳定技能。公共机制允许比 Kin 的亲眼所见更广泛，如同真人查教程；具体世界位置、他人行为和物品权属仍受[感知边界](architecture.md)约束。

世界书提供公共知识起点；Kin 亲历的失败、成功与尚待验证的方法由[自主学习设计](learning.md)管理。自身经历不能静默改写整个版本的公共机制条目：发现冲突时要保留游戏结果和原资料，标记版本、服务器条件及待核查问题。

## 验收方向

在锁定 Java 版本后构造三组题：通用生存常识、本版本新增/变更内容、旧版本攻略或未知内容。检查它是否检索到匹配版本的知识、是否说明前提、是否在不确定时查询或承认未知，以及真实试验失败后是否修订。断网时应继续用已核实基础知识游戏，不把猜测说成确定机制；见[路线图](roadmap.md)。
