# 居住与行路策略：家园、游走和地点选择

普通玩家不都按“先撸树 → 建房 → 找矿”的固定顺序生活。Kin 首登后可以决定尽快有个家、先搭临时据点、带床行走或在旅途中慢慢挑选喜欢的地方；这些是**生活策略与地点承诺**，与人格有关，却不等同于善恶或建造知识分数。人格影响安全感、对地点/朋友的依恋、探索欲与耐心；当前资源、目标、可观察环境和经历决定是否真的定居。

| 策略 | 角色可能想要的生活 | 需要权衡的代价 |
| --- | --- | --- |
| 定居 | 找较平坦的区域建家，存放物资、种田并逐渐扩建 | 时间、材料、领地约定、距朋友/目标地点的路程 |
| 临时据点 | 先搭工作台/床/庇护，之后再选长期家 | 易搬但要记住物品和旧位置，可能浪费临时建设 |
| 游走 | 床与装备随身，今天探索，明天在别处过夜 | 背包空间、补给与回程、临时地点安全；可随经历改变主意 |
| 混合 | 有物资基地但经常远行，途中再建小驿站 | 物品与床/驿站位置需要有出处的地图记忆和检查 |

地点评估只能用 Kin 真实看见、探索过或朋友告知且标为陈述的信息。例如平坦程度、周边木材/水源、危险、可建造空间、朋友住处、公开共享约定及已知探索路线；候选地不需是整个世界里的“全局最优”。家是可持续修改的目标：搬家、修屋顶、扩建农田、守住私人箱子，都可与安全、速通或朋友承诺竞争。游走 Kin 则不必因为“无基地”被系统判为发展失败。

下界门的选址也可成为一个中期地点项目：有人在家附近放门方便往返，有人离家一段距离便于路线或避免打扰，还有人直到实际探索才决定。规划考虑已知路线、材料、防护和与伙伴约定，进入下界后以合法探索结果修订；跨维度对应关系和具体版本机制由[世界书](world-guide.md)与后续专题调研提供，不能查询未经观察的全图坐标。选址是角色权衡而非硬编码“最佳位置”。

策略可以变：爱远游的 Kin 遗失物资后想建仓库，依恋家的 Kin 认识喜欢探险的朋友后设立前哨站。重要决策保存候选地点、已知优劣、未知、所选理由、投入的材料/时间、权属约定及后续结果。**对家园的归属感**来自真实投入和经历，不在首登前虚构它盖过的房子；[目标设计](goals.md)、[权属与记忆](player-mind.md)记录建造后的承诺。

此前开放问题已形成[地点评估、资产迁移与传送门契约](settlement-location-contract.md)：普通模式以视锥内有限首命中射线、亲自行走/碰撞结果和有时间戳的地点记忆构造不完整 patch；禁止以客户端区块已加载、整列高度图或任意方块查询代替看见。床/箱/炉/工作台以事务式资产账本迁移，旧地点回访先重验；传送门只按公共机制形成粗略预期，实际端点必须穿越后记录。首批回放比较定居、临时据点与游走选择及真实行动，不保证自动选出漂亮、完美或全球最优的家园；外部 VLM 默认调用为零。
