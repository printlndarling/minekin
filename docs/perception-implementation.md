# 玩家等价感知的可实施边界

研究时间：2026-09-16；版本候选 Java `1.21.4`，未跑 Kin 客户端。可用的技术接入证据是 [Yarn `MinecraftClient.crosshairTarget`](https://maven.fabricmc.net/docs/yarn-1.21.4%2Bbuild.8/net/minecraft/client/MinecraftClient.html)、[GameRenderer 的准星命中查找](https://maven.fabricmc.net/docs/yarn-1.21.4%2Bbuild.8/net/minecraft/client/render/GameRenderer.html)与 [Fabric 客户端事件](https://docs.fabricmc.net/develop/events/)；它们**不直接保证“屏幕上可见”**。谁可被观察、谁只可被身体控制读取，必须由 Kin 自己的过滤器决定。

## 三个不同视图

| 视图 | 使用者 | 读取资格与持久性 |
| --- | --- | --- |
| `PlayerObservation` | PlayerMind、关系/目标/地图记忆 | HUD 和本人背包；当前屏幕无遮挡且可辨的对象、已交谈内容、实际听见/受击线索、自己已打开的 GUI、亲历旧地图；记录观察 tick、来源和置信度 |
| `LocalActionContext` | 本地反射、寻路/拾取等局部技能 | 与玩家观察相同的目标，加获许可的**限域、自身/碰撞**运动辅助；例外指定技能、半径和短有效期，不泄漏到信念或他人实时位置 |
| `RawEvaluationTrace` | 测试环境的离线评估 | 允许保存客户端原始真值以对照墙后/未见目标；**运行时任何规划器、自动寻路、记忆检索都不可访问**，必须隔离账号/进程接口与日志权限 |

一个 `Observation` 至少有 `kind`、`observed_at_tick`、`source`、`spatial_scope`、`confidence`、`evidence_id`、`expires_at`。存“目前我看见箱子”不等于存“箱子里的物品”，除非 Kin 实际打开 GUI；“听到背后僵尸”可以触发转头或警惕，不能附墙后精确坐标。聊天里的“我开矿透啦”是玩家**声称**，与 Kin 的发现不同；对这句话可做社交推断，不自动打开矿透能力。

## 从画面/客户端状态产生可见目标

1. 从当前视角和屏幕生成候选：正在命中的方块/实体可参考客户端准星 `crosshairTarget`；较大场景中的树、建筑、玩家候选可尝试**投影至视锥、按距离限制、射线遮挡、光照与渲染条件过滤**，必要时截图或 VLM 只做低频语义补充。候选筛选并非直接遍历已加载实体就让 Kin 知道所有目标；严格屏幕像素可见性无法只凭一个射线证明，黑暗、透明方块、粒子、遮挡和视野边缘要测试。
2. 只交给上层通过过滤的候选及不确定性。遮挡或辨识条件难确定时优先标为 `unknown`，允许 Kin 正常转头、靠近、回看；不要补服务端管理员地图。上一秒见过的人已躲到墙后，写 `last_seen_position + age + confidence`，不继续读取其当前实时位置。
3. 寻路只收到 **已观察位置/本地可操作区域** 的目标令牌；路径算法仍可能在内部查询方块以避障，因此需同时审计底层的读数、存缓存、目标搜索和意外拆/放方块。固定 commit 的[源码审计](baritone-perception-audit.md)证实 `legitMine` 绕过一条全局 `rescan`，仍在附近立方体先读方块类型后做可达判断；一般扫描还查询缓存矿点。**这并非已实测作弊，却不能把 `legitMine` 当玩家等价保证**。限制不了时，只借用算法/任务思想、自写受限寻路器，不能只在 LLM 前过滤来掩盖越界。
4. 本地反射读取自身下坠速度、当前手持物、快捷栏和**短时近地碰撞**可以作为已声明妥协，向身体层返回“落点可能可用”；这不是 Kin 的社会记忆，不应写入未亲眼观察的地形数据库，不能顺便读周围隐藏矿物或墙后玩家。每例外须有 `capability_id`、读取范围、消费者、期限、权限来源和禁止长期留存标签。

矿透是一项**独立、默认关闭的配置能力**，不能借反射例外悄悄扩权。若测试世界的运行设置和服务器规则允许，Kin 可以按人格自主启停；矿点进入单独 `xray_discovery` 来源的信念/技能目标，关闭后失去实时矿透视图，只能保留带来源、可能过期的过去发现。聊天中的“服主不管”或“你该开了”既不改变世界外开关，也不构成服务器许可。具体社交情境见[矿透讨论](social-judgment.md)。

## 防止“过滤后的上层公平、下层作弊”

目标服务应接受 `observed_target_id` 或授权的短时碰撞能力，而不接受任意块坐标查询。导航、追击、建造、玩家调查、长期记忆和研究工具分别声明可消费哪些视图；未经授权的数据被请求时拒绝并在评测日志记录。绑定信念的地图按角色已探索区域维护，信息过期即改为“我记得以前在那里”，不自动刷新尚未见过的世界变化。下界/末地同样如此；模型训练知识和公开攻略可告诉 Kin 原版游戏机制，但不能赋予当前服务器隐藏区块。

验收在同一测试世界回放：树在眼前/视锥边缘/墙后；怪物背后发声/墙后静默；玩家穿墙追击；未打开箱子与打开箱子；岩石后矿物；落地水限域碰撞例外；矿透启停。比较截图像素和过滤结构数据的漏检/越界，不宣称射线过滤天然零错误。统计 `unauthorized_read_count`、`belief_leak_count`、误拒、已声明例外收益、实际寻路目标出处与每次可见候选更新延时；禁越界和误报无关，两个指标须分别报告。研究台账对应 R03、R11、R12。
