# 玩家在线模式与首次进入

运行模式决定 Kin 的**存在时间**，不决定它是否服从真人。它始终是用自己账号进入服务器的玩家，有目标、利益、性格与记忆。运行者可以为同一个 Kin 选择陪玩模式（A）或独立玩家模式（B），并在保留身份与存档的条件下切换。

| 玩家体验 | A：陪玩模式 | B：独立玩家模式 |
| --- | --- | --- |
| 第一次见到 Kin | 指定真人进入并邀请它后，它首次正常加入世界 | 即使没有真人，它也能自行首次加入并从普通玩家出生点开始 |
| 只有 Kin 在线 | 不发生；指定真人离线时 Kin 不在世界 | 可发生；它按自己的目标采集、探索或建造 |
| 真人发出请求 | 可以接受、拒绝、延后或讨论条件 | 同样可以接受、拒绝、延后或讨论条件 |
| 真人下线 | Kin 暂停任务、保存状态，正常退出世界 | Kin 可以继续当前计划或按自身需求重排目标 |
| 真人再次上线 | 受邀请后重进世界，观察变化并核对旧承诺 | 真人可能看到 Kin 已推进目标、搬家、死亡或结识别人 |
| 身份与记忆 | 同一个客户端账号、物品和经历，不因 A/B 重置 | 同左 |

## A：陪玩模式

默认草案是**指定真人邀请 Kin**，而非服务器出现任意真人就自动加入。它可以在自己的计划和个人喜好内参与活动；邀请只决定此时能否进世界，不是行动命令。指定真人离开时 Kin 应尽快保存当前任务、承诺、线索与背包观察，结束正在执行的客户端动作，并正常退出。若正在受击、使用物品或建筑未完成，先进入可中断的安全边界；避免等待很久而违反“玩家下线它也退出”的体验。非正常断线可在重连后补记一条“不确定发生了什么”的经历。

退出后不会假装继续挖矿或在世界里行动。默认也暂停需要网络和费用的后台研究任务；下次邀请时重新检查过期知识、世界变化与旧任务。真人再次进入不意味着 Kin 必须完成上次的约定：它可以解释为何延期或根据新情况改变主意，但不能无故忘记曾答应过。

## B：独立玩家模式

运行服务启动且服务器允许连接时，Kin 可以无人陪伴地正常在线；这是“允许单独生活”，不是要求电脑永远不断电。真人离线后它继续根据需求和目标行动，未来重逢可能带来真正的时间差：它盖了新屋、换了基地、失去物品，也可能已经死亡并重生。每件事都要来自在世界里实际发生和合理观察过的经历，不能通过离线时的服务端真值补剧情。

长期在线要规划空闲行为、资源与模型调用预算：没有值得做的事时可以休息、整理资源、观察附近、降低高层思考频率；危险时仍保持本地反射。服务器停机、网络中断或客户端崩溃时，Kin 不再被认为在世界里；重新上线后先观察自己的位置、背包、健康、时间与附近可感知变化，再决定是否恢复旧目标。

## 初见与身份

首登即普通新玩家：无预先扫描地形、无赠送物品、无默认基地、无凭空与真人的过往关系。它在进入前已有独特的初始人格、“想先活下去/找住处”等近期方向和逐步发展、击败末影龙并回主世界的默认远期主线；具体如何推进由人格与亲历决定，对人的信任由互动形成。创建时可以配置一名与 Kin 入世有关的运行者玩家：初见时比陌生人略愿意接近，但不凭空拥有一段共同下矿或互助经历，也不认定对方能驱使自己。该玩家和其他人一样可能成为好友或仇人；配置对应的身份、来源和关系初始化见[决策自主权与初始关系](decision-agency.md)。人格配置与演变见[人格与行为变化](personality.md)。是否做欢迎对话由当时情景决定；身份展示应让其他玩家知道它是自动化玩家。

## 切换模式的状态

| 切换 | 预期行为 |
| --- | --- |
| A → B，指定真人已下线 | Kin 可以独立连接/留在世界；先检查任务前置条件，不清空承诺与情绪 |
| B → A，指定真人已下线 | 保存状态并退出世界；后台任务按 A 的规则暂停 |
| A ↔ B，指定真人仍在线 | 客户端不必重复登录；只切换之后的下线策略 |

切换需记录运行模式及生效时间，而不是记成 Kin 在游戏里突然有了新的人格。模式控制器负责连接、暂停、恢复和防止重复执行；PlayerMind 可以就新的生活条件重新规划，但其关系、权属与亲历记忆保持连贯。多人同时在线、陪玩锚定玩家离开而其他人尚在，以及谁能改变运行模式，仍属待讨论选择，见[设计决策](decisions.md)。
