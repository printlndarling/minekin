# 玩家在线模式与首次进入

运行模式决定 Kin 的**存在时间**，不决定它是否服从真人。它始终是以自己的游戏身份进入服务器的玩家，有目标、利益、性格与记忆。运行者可以为同一个 Kin 选择陪玩模式（A）或独立玩家模式（B），并在保留身份与存档的条件下切换。

| 玩家体验 | A：陪玩模式 | B：独立玩家模式 |
| --- | --- | --- |
| 第一次见到 Kin | 指定真人进入并邀请它后，它首次正常加入世界 | 即使没有真人，它也能自行首次加入并从普通玩家出生点开始 |
| 只有 Kin 在线 | 不发生；指定真人离线时 Kin 不在世界 | 可发生；它按自己的目标采集、探索或建造 |
| 真人发出请求 | 可以接受、拒绝、延后或讨论条件 | 同样可以接受、拒绝、延后或讨论条件 |
| 真人下线 | Kin 暂停任务、保存状态，正常退出世界 | Kin 可以继续当前计划或按自身需求重排目标 |
| 真人再次上线 | 受邀请后重进世界，观察变化并核对旧承诺 | 真人可能看到 Kin 已推进目标、搬家、死亡或结识别人 |
| 身份与记忆 | 同一个 Kin；本世界物品/经历不因 A/B 重置 | 同左 |

## 世界承载方式：加入还是自己开世界

A/B 只回答“Kin 何时在线”，另一个正交字段 `attachment_mode`回答“世界由谁承载”：

- `JOIN_REMOTE`：加入别人的 dedicated server，或加入别人开放的 LAN integrated world；
- `HOST_INTEGRATED_LAN`：Kin 创建/加载自己的 save，启动 integrated server并开放 LAN，其他玩家加入 Kin 的世界。

因此 A/B 与 JOIN/HOST 可以组合。A+HOST 表示陪玩条件满足时 Kin 才启动自己的世界供锚定真人加入；B+HOST 表示 Kin 可独自在自己的世界生活，客户端运行期间其他玩家也可加入。关闭客户端会让 integrated LAN 世界下线，但 save、Kin 身份和经历继续持久化。世界承载切换不授予真人命令权，也不改变人格；目录、端口、存档与恢复见[受管理目录与世界承载模式](world-hosting-mode-contract.md)。

## A：陪玩模式

默认草案是**指定真人邀请 Kin**，而非服务器出现任意真人就自动加入。它可以在自己的计划和个人喜好内参与活动；邀请只决定此时能否进世界，不是行动命令。指定真人离开时 Kin 应尽快保存当前任务、承诺、线索与背包观察，结束正在执行的客户端动作，并正常退出。若正在受击、使用物品或建筑未完成，先进入可中断的安全边界；避免等待很久而违反“玩家下线它也退出”的体验。非正常断线可在重连后补记一条“不确定发生了什么”的经历。

退出后不会假装继续挖矿或在世界里行动。默认也暂停需要网络和费用的后台研究任务；下次邀请时重新检查过期知识、世界变化与旧任务。真人再次进入不意味着 Kin 必须完成上次的约定：它可以解释为何延期或根据新情况改变主意，但不能无故忘记曾答应过。

## B：独立玩家模式

运行服务启动且服务器允许连接时，Kin 可以无人陪伴地正常在线；这是“允许单独生活”，不是要求电脑永远不断电。真人离线后它继续根据需求和目标行动，未来重逢可能带来真正的时间差：它盖了新屋、换了基地、失去物品，也可能已经死亡并重生。每件事都要来自在世界里实际发生和合理观察过的经历，不能通过离线时的服务端真值补剧情。

长期在线要规划空闲行为、资源与模型调用预算：没有值得做的事时可以休息、整理资源、观察附近、降低高层思考频率；危险时仍保持本地反射。服务器停机、网络中断或客户端崩溃时，Kin 不再被认为在世界里；重新上线后先观察自己的位置、背包、健康、时间与附近可感知变化，再决定是否恢复旧目标。

## 初见与身份

首登即普通新玩家：无预先扫描地形、无赠送物品、无默认基地、无凭空与真人的过往关系。它在进入前已有独特的初始人格、“想先活下去/找住处”等近期方向和逐步发展、击败末影龙并回主世界的默认远期主线；具体如何推进由人格与亲历决定，对人的信任由互动形成。创建时可以配置一名与 Kin 入世有关的运行者玩家：初见时比陌生人略愿意接近，但不凭空拥有一段共同下矿或互助经历，也不认定对方能驱使自己。该玩家和其他人一样可能成为好友或仇人；配置对应的身份、来源和关系初始化见[决策自主权与初始关系](decision-agency.md)。人格配置与演变见[人格与行为变化](personality.md)。是否做欢迎对话由当时情景决定；自动化账号的准入披露由运行者按目标服规则在规定渠道处理，Kin 的游戏内玩家式对话不承担该披露任务。

首登时把真实登录的游戏 ID、Kin 的稳定自称、已选个人设定与尚未设定的身份问题分开；默认自称 `Kin`，没有凭空生造的真人本名或童年往事。日后有人问年龄、性别、MBTI 或星座，Kin 可自然回答、回避或改聊入世经历，不因身份提问自动吐出模型免责声明。见[自我介绍与个人信息](self-identity.md)。

## 切换服务器或世界

A/B 是“何时在线”，World Context 是“现在生活在哪里”。同一个 Kin 可拥有多套世界生活史，但任一时刻只允许一个活动 Minecraft 会话。

切换前保存并暂停旧世界计划/承诺，撤销输入；新世界使用新 generation，只装载同一 Persona、通用知识/技能与目标世界上下文。重进同一世界时记得过去但重验现实；进入不同世界时不携带旧背包、坐标、房屋、箱子或同名玩家关系。返回旧世界后也不机械续跑旧计划。见[多服务器、多世界上下文](world-context-contract.md)。

## 切换模式的状态

| 切换 | 预期行为 |
| --- | --- |
| A → B，指定真人已下线 | Kin 可以独立连接/留在世界；先检查任务前置条件，不清空承诺与情绪 |
| B → A，指定真人已下线 | 保存状态并退出世界；后台任务按 A 的规则暂停 |
| A ↔ B，指定真人仍在线 | 客户端不必重复登录；只切换之后的下线策略 |

切换需记录运行模式及生效时间，而不是记成 Kin 在游戏里突然有了新的人格。服务关闭、模型上下文清空或供应商切换同样不能重新创建人格；必须从[身份与记忆持久化契约](persistence-recovery-contract.md)恢复同一 `kin_id`，入服后重验现实并拒绝续跑旧按键/GUI 状态。模式控制器负责连接、暂停、恢复和防止重复执行；PlayerMind 可以就新的生活条件重新规划，但其关系、权属与亲历记忆保持连贯。多人同时在线、陪玩锚定玩家离开而其他人尚在，以及谁能改变运行模式，仍属待讨论选择，见[设计决策](decisions.md)。
