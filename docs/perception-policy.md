# 玩家等价感知与有限例外

Kin 以普通玩家能合理获得的信息为基准，但不依赖持续上传画面给多模态大模型。自身 HUD/背包、可见场景、声音、触碰、亲历记忆可以通过结构化方式获取；外部视觉模型默认关闭，只在结构化观察及本地方法仍无法满足特定复杂语义任务、且已配置费用/隐私权限时按需使用；截图主要用于离线校准。紧急动作由本地控制，不等待模型。

| 范围 | 例子 | 处理方式 |
| --- | --- | --- |
| 玩家等价信息 | 自身状态、当前无遮挡视野、聊天、声音、自己打开的界面、曾探索地点 | 可以进入 Kin 的信念与记忆；旧观察会过期 |
| 等价数据辅助 | HUD 数值、眼前方块、可见实体的名称与相对方向 | 减少识别成本，但同样检查视野、遮挡与来源 |
| 有限妥协 | 为本地落地水获取自己的精确运动数据，或近距离避障时读取限域碰撞信息 | 只供指定技能短时使用；默认不能进入世界信念或长期地图 |
| 默认不可用的隐藏信息 | 未暴露地下矿物、墙后玩家即时坐标、他人背包、未打开箱内物、世界 seed、私有服务端设置 | 不由普通模式或底层技能暗中使用；特定矿物信息仅在另行配置并主动启用矿透模式时可用 |

出于成本或技术困难允许少量数据读取妥协。新增例外需声明体验问题、读取字段、使用模块、距离和有效时间、能否入记忆、服务器规则与停止条件。**玩家主动选择开矿透**则是另一类改变世界感知的行为，必须有独立能力配置、可见模式开关、矿点来源标签和游戏内社会判断；不是落地水例外逐渐扩权，也不能因底层库已经能读而自动启用。见[社会判断场景](social-judgment.md)。

感知约束必须覆盖执行层。只过滤 LLM 不能阻止自动寻路器扫描隐藏矿物。[Baritone 1.21.4 源码审计](baritone-perception-audit.md)显示一般采矿目标会查缓存矿点/已加载 chunk，而 `legitMine` 附近仍先读方块状态、再判可达；它可作为导航算法候选，但**普通模式不能直接用默认扫描作目标发现**，缓存和全路径读数仍需实际审计。[AltoClef](https://github.com/gaucho-matrero/altoclef)提供任务分解思路，其原项目依赖 Baritone 且已归档，同样不能未经测试直接接入。若无法限制它们读取的地图、目标和动作，只借用算法或实现受限适配器。普通模式禁止隐蔽找矿；经主动启用的矿透模式可以选择该模式发现的矿点，两种情形都记录出处。

具体字段划分、客户端候选观察、动作例外与底层寻路读数的实施路线及截图回放，见[玩家等价感知实施](perception-implementation.md)。

在私人世界回放跌落、避障、墙后实体和埋藏矿物，记录 `capability_id`、字段、距离/时间、消费者、是否写入信念及最终动作。分别报告已声明例外的使用与收益、未授权读取、例外污染长期信念的次数；未授权次数的目标是零，合法例外则如实公开。测试日志可保留真值作离线对照，Kin 在线不可访问评测真值。
