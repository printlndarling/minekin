# 玩家等价感知与有限例外

Kin 以普通玩家能合理获得的信息为基准，但不依赖持续上传画面给多模态大模型。自身 HUD/背包、可见场景、声音、触碰、亲历记忆可以通过结构化方式获取；视觉模型仅在复杂语义场景按需使用。紧急动作由本地控制，不等待模型。

| 范围 | 例子 | 处理方式 |
| --- | --- | --- |
| 玩家等价信息 | 自身状态、当前无遮挡视野、聊天、声音、自己打开的界面、曾探索地点 | 可以进入 Kin 的信念与记忆；旧观察会过期 |
| 等价数据辅助 | HUD 数值、眼前方块、可见实体的名称与相对方向 | 减少识别成本，但同样检查视野、遮挡与来源 |
| 有限妥协 | 为本地落地水获取自己的精确运动数据，或近距离避障时读取限域碰撞信息 | 只供指定技能短时使用；默认不能进入世界信念或长期地图 |
| 隐藏世界真值 | 未暴露地下矿物、墙后玩家的即时坐标、他人背包、未打开箱内物、世界 seed、私有服务端设置 | 不能成为找矿、社交归因或长期目标的依据 |

出于成本或技术困难允许少量数据读取妥协。新增例外需声明体验问题、读取字段、使用模块、距离和有效时间、能否入记忆、服务器规则与停止条件。若需要将超过正常可见范围的信息供高层决策，必须另外明确讨论；不能把底层库已经能读视为默认授权。私人测试服和公开服务器可配置不同允许范围。

感知约束必须覆盖执行层。只过滤 LLM 不能阻止自动寻路器扫描隐藏矿物。[Baritone](https://github.com/cabaletta/baritone)可作为导航算法参考，但其自动采矿、缓存和目标查找需要审计；[AltoClef](https://github.com/gaucho-matrero/altoclef)提供任务分解思路，其原项目依赖 Baritone 且已归档，同样不能未经测试直接接入。若无法限制它们读取的地图、目标和动作，只借用算法或实现受限适配器。合法例外用于提高本地操作能力，不是隐蔽资源搜索。

在私人世界回放跌落、避障、墙后实体和埋藏矿物，记录 `capability_id`、字段、距离/时间、消费者、是否写入信念及最终动作。分别报告已声明例外的使用与收益、未授权读取、例外污染长期信念的次数；未授权次数的目标是零，合法例外则如实公开。测试日志可保留真值作离线对照，Kin 在线不可访问评测真值。
