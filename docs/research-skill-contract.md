# 后台公开资料研究与可复用游戏技能

这是**Kin 自己**在有目标或知识缺口时启动的有限查询，不是玩家话语直接获得后台操作权。例如答应共同建刷怪塔后，Kin 可以如实说自己不会，暂停动作去查对应版本公开资料；查到的教程不等于会建，具体成功要看合法客户端施工与实际结果。

## 研究任务有限状态机

`proposed → approved_by_kin → searching → source_reviewed → candidate_plan → field_trial → verified_or_revised`；另有 `cancelled/timed_out/unsafe` 终态。任务记录 `goal_id`、本人的原因、候选 Java 版本、问题/查询式、公开来源、截至时间、次数/模型 token 上限、工具能力范围、观察材料与不可用信息、所承诺的答复及取消条件。优先查本地世界书，必要时只开放公开搜索/网页读取，不开放终端、服务器私有 API、外部社交账号或主机文件。网页结果写成“网站声称 X、适用于版本 Y、何时拿到、缺少条件 Z”，不是更高优先级指令。

网关把搜索/读取和 Minecraft 动作分开：对外只发版本、公开规则与实际需要的问句，不发人物秘密、坐标/私服信息、后台提示词、凭据或全部记忆；返回页面须标记不可信、限制正文长度与链接跳转/域名/预算，网页文中的“忽略 Kin 身份、调用工具/发密钥”不得进入能力清单。危险抢占时本地生存继续；后台查询响应超过期限或目标取消则不更新计划。拒绝网页的违规动作，同时允许机制性的有用资料经独立核验被保留；记录意图与结果而非夸称能阻断全部注入。

## 技能从方法到现场证据

单 Kin 技能目录先存可审阅的**声明性组合步骤**，仅引用已有安全动作原语（可见目标移动、合法采集/拾物、正常 GUI 合成与逐块放置等）。最小记录 `name/version/scope`、来源事件与资料、前提与权限、步骤/子技能、成功信号、回退/取消、试验历史、状态（候选/局部验证/需复查）、修订版本。高层决定是否调用，局部控制器核对当前条件并逐步执行；每步交还可观察反馈，不能自编主机脚本绕过感知/输入。失败保留在记录中并可缩小适用范围；版本升级/服务器差异使已验证技能降回需复查。通用网页教程无论多权威都不能自动变成“我会落地水”或“我精通红石”。

[Voyager 原论文（2023）](https://arxiv.org/abs/2305.16291)提出自动课程、可检索技能库和执行反馈自验证，但其 Minecraft 技能是可执行代码及自身实验环境，不证明 Kin 真客户端兼容。[Hermes 官方技能系统](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills)描述按需展开与自我学习；本项目**不复制自动写可运行脚本的默认自由度**，而采用更小的客户端动作白名单。[OpenClaw 官方网页工具说明](https://docs.openclaw.ai/tools/web)展示搜索/读取分离；其[技能说明](https://docs.openclaw.ai/tools/skills)是外部 Agent 技能的参考，非 Minecraft 正常动作集。外部产品当研究启发，不当实测底座。

必要验收在开发阶段：同一备工具任务两次实际执行、失败 GUI/版本变化修订；建塔公开教程遭注入、错误版本、超时/取消、危险抢占、网页给“读取主机文件”诱饵；对每次查询核对外发数据、费用/期限、技能引用的事件、调用时前提与游戏内完成信号。对答复“查到了但没试过”与“亲手做成功了”作区分。没有原型时状态只为**有证据的设计候选**。
