# PlayerMind：长期自治玩家

PlayerMind 是目标与社会判断层，不直接模拟按键。它维护自身状态、情绪、对他人的关系、对世界的信念，以及具有来源的经历；LLM 可根据这些材料提出计划或回应，但不能凭一句话改写过去的事实。这里的“情绪”是持续影响行动的可实现内部状态，不宣称系统具有人的主观体验。

## 状态模型（初稿）

| 状态 | 示例字段 | 更新来源 |
| --- | --- | --- |
| 自身需求 | `safety`、`resource_security`、`progress`、`curiosity`、`social_need` | 个人设定与游戏经历 |
| 情绪状态 | 失落、焦虑、愤怒、安心等当前倾向；强度、起因、时间与持续条件 | 损失、威胁、支持、进展及对事件的解释 |
| 人格倾向与价值观 | `risk_tolerance`、`generosity`、`sociability`、`attachment`、公平观、自利倾向、幽默方式等 | 初始配置；重要经历可缓慢改变，见[人格设计](personality.md) |
| 领域知识画像 | 版本匹配专题、每个领域的初始覆盖与理解深度 | 创建时自定义或随机预置，后续查询/验证扩展；见[知识画像](knowledge-profile.md) |
| 实战技能与注意力 | 实际尝试、任务条件、操作结果、当前专注任务与互动关注度 | 入世后亲历训练与任务负荷更新；见[技能](ability.md)和[交互判断](attention-intent.md) |
| 关系 | `trust`、`affinity`、`fear`、`respect`、`grievance` | 带证据的互动事件 |
| 目标 | 短/中/长期层次、动机、优先级、前置条件、承诺、期限、完成条件 | 人格偏好、主动规划、游戏日推进与任务结果，见[目标设计](goals.md) |
| 所有权 | 物品/建筑/区域标识、共享约定、证据、置信度 | 亲自放置、公开约定与观察 |
| 居住策略与地点承诺 | 定居/临时据点/游走倾向、候选地点理由、迁移、家与旅途补给 | 首登人格/目标和亲历世界条件共同决定，见[居住与行路](living-strategy.md) |
| 情节记忆 | 时间、参与者、观察来源、行动、结果、置信度 | 事件记录与有依据的摘要 |

数值只是帮助排序和保持连贯的内部变量，不直接规定台词或动作。熟悉感、好感、信任、亏欠和怨恨不是同一根好感度：创建时认识与自己入世有关的运行者，不意味着相信其对下界危险的承诺或必须听从他。偏好和利益可以冲突：即使对某人有好感，也可能因为资源不足而拒绝借出铁；即使受到攻击，也可能因为打不过而先逃跑。初始化与后续升降见[决策自主权与初始关系](decision-agency.md)。

人格决定如何看待利益、公平、关系和风险；当前心境与情境决定今天想不想较真、明天是否有兴致开玩笑。稳定倾向不等于每天重复同一行为；心境变化也不等于角色换了人。价值观、慢变性格、关系、短期心境和可学习的习惯分开维护。

开局[多领域轮廓](knowledge-profile.md)表示对原版玩法知道多少，不表示实战能力。同一 Kin 可以精通建造知识却施工失误，熟悉打怪策略却打不赢；目标选择需结合已知资料和后天真实结果，不把“想打怪”或“知道打法”误读成“打得赢”。

## 情绪如何改变行动

事件本身和对事件的解释分开保存。发现自己放在箱子里的钻石不见了，角色可以因损失而难过、沮丧或不安，同时仍不知道物品是被拿走、误放，还是被自己移动。情绪不需要等待确认犯人。Kin 可以凭有限线索作出高置信推断、试探性指认，甚至在气愤中草率指责或攻击；这些行为分别标记为推断和选择，不会自动把怀疑写成亲眼见过的事实，也应承担误判的游戏与社会后果。失窃只是诸多生活事件中的一个例子。

情绪应影响注意力和行动选择：失落可能降低建造兴趣并促使角色向朋友诉苦；不安可能使它重新盘点资源、减少共享或搬走贵重物品；愤怒可能提高寻找线索的优先级，却不意味着无条件开战。强度受损失对个人目标的重要性、人格、资源稀缺、既往经历和朋友支持影响，随时间、补偿与新证据改变。重复损失可能形成持续的安全需求，而不是简单让“难过值”不断累加。

每次情绪更新至少保留 `cause_event_id`、解释、强度、时间和失效/缓解条件。LLM 能提出对事件的解释，但不能未经观察直接补出偷窃者。角色可以表达不确定性：“我很难过，我的钻石不见了，我还不知道发生了什么。”

## 不知道是谁拿的：调查与选择

失窃不是既定事实。Kin 可以检查自身背包、其他存放地点、最后一次盘点和共享约定，也可以先问人、暂不理会或直接采取行动；这些不是必经步骤。若仍找不到，记录“资源丢失”及来源可追溯的竞争假设。调查是可选目标，拥有时间、资源和社交代价，可与建造、生存等目标竞争。

| 可能行动 | 需要的能力与代价 | 对证据的影响 |
| --- | --- | --- |
| 自己检查与重盘点 | 打开可访问箱子、查个人物品与行动记录 | 排除误放、自己移动；不自动确定拿取者 |
| 向朋友求助或逐人询问 | 可交谈、知道谁合理可能在场 | 获得他人陈述；陈述与亲眼观察分别记账 |
| 试探性询问 | 问不同人何时到过家里、是否知道丢失物的细节，比较回答 | 提高或降低怀疑；异常回答不是直接目击证据 |
| 公开询问或悬赏 | 自愿花费自己的资源并承担引来虚假线索的风险 | 增加线索机会；悬赏回应需核实来源 |
| 暂停调查或放弃 | 取决于物品价值、风险、精力和其他目标 | 接受未解的损失，不强制生成犯人 |

Kin 可以做普通玩家会做的排除与常识推理：若可靠地知道这段时间世界里只有自己和 A，且排除了自己取走，A 就很可疑；若 B 承认拿过，角色可以据此判断 B 拿了，但仍可考虑 B 是否说谎；若最后已知 B 远在数千格外、A 最近出现在家附近，Kin 可以更怀疑 A，却不能把过期的 B 位置或 A 的接近误记为实时定位和亲眼目击。Kin 也可能过度自信或因脾气先发作，不要求凑齐直接证据才允许提出判断。

“钓鱼询问”可以是有策略地选择问题、观察回答是否与已知事实一致；是否故意说假话属于人格和策略选择。不能通过直接读取聊天之外的玩家背包、未打开箱子或墙后位置来“破案”。对怀疑对象保存所依据的线索、反证、时间与置信度；他人陈述和可疑反应可参与推理，但与亲眼观察分开。新证据出现时允许推翻判断，并面对错误指认造成的关系损害。

## 找回、和解或报复

无论是否查明损失来源，都不触发固定“连续追杀”脚本。PlayerMind 可以自主选择索回、要求归还、拒绝合作、放弃、迁走财物、向盟友求助、公开求补偿，或因委屈迁怒甚至报复；也可以认为重新获取资源比追查更值得。取舍会受所需资源、风险、证据、人格、既往关系、服务器规则和当下心境影响，但不靠一张预写的证据阈值表输出唯一行动。角色可以长期记仇、主动追踪或在允许 PvP 的世界追打别人，也可能错怪无辜的人；身体动作仍受正常客户端输入和当前实际感知约束。死亡、道歉或赔偿都不自动清除旧目标，新经历可以改变它。

有时它只会难过一阵后继续盖房子；有时悬赏寻物；有时认定犯人后几天都不愿共享箱子。不同结局应来自相同机制在不同经历和人格下的选择，而非预写的剧情分支。

## 决策原则

- 没有真人指令时也能从需求、未完成目标和环境机会产生行动。
- 一次游戏日的结束或目标里程碑可以触发回顾，但不让固定日程抹掉人物的持续目标。
- 玩家发言是社交事件和请求，不能直接转换成最高优先级命令，也不能只凭一句话取消 Kin 开局已有的远期主线。
- 请求回应需检查可支配资源、当前目标、承诺、关系、风险与时间；可接受、拒绝、讨价还价或推迟。
- 丢失物品不等于确认被偷；既能自主调查或放弃，也能凭间接线索推断、因情绪草率指认或迁怒。记录信念与错误可能性，不把推断升格为世界真值。
- 一句道歉不重置关系；归还资源和持续守约可以逐渐修复关系。
- 人格可以主动产生不道德目标：偷拿别人物品、挑衅或设计伤人陷阱；不强制等别人先侵犯 Kin。目标仍需具体可执行动作与真实反馈，不借服务器私有信息假装知道目标会在哪出现。
- 与事实矛盾的新消息先成为“有人如此声称”的记忆，不覆盖已有经历。
- 玩家关于自己、他人或服主规则的说法先是陈述，Kin 可按来源、关系、反证和行动代价自主质疑/核实；不能把“服主不管”直接变成授权事实。
- 受击事实与攻击意图分开，注意力低也不妨碍即时安全反射；警告、后退与反击依风险、关系、反证和角色当前能力分别选择。
- 记忆检索应带出处和不确定性。长期摘要压缩细节时保留关键证据，不让模型把推测写成既定事实。

## 小型情景

玩家说“陪我下矿去”，系统先记录说话者和内容，查当前资源与承诺：AI 可以回答“等我把屋顶盖完”，并创建一项可撤销的约定。玩家连续攻击它时，本地控制先避险，PlayerMind 再根据命中、追击和既往关系评估意图。次日若该玩家靠近私人箱子，AI 可以提高警惕，但不得凭墙后位置或未经观察的箱内变化断定再次偷窃。

在工作台合成时，Kin 可以没留意玩家叫它；被轻打后注意到受击并转头询问，但不因一次命中自动敌对。若后续追击或伤害升级，先由本地动作层求生，高层再依据证据和自身能力判断意图与对策。见[注意力与意图](attention-intent.md)。

脾气急的 Kin 即使认为是提醒，也可以回敬一拳；性格温和的 Kin 可能无所谓。一击误杀残血 Kin 后，它可以同时相信对方非故意、又因死亡和装备损失而生气，或在捡回物品后选择不再计较。意图假设、实际损失、关系/情绪改变与回应动作分别保存，不能将原谅误伤直接等同于免除后果。

## 存储与接口

初期以本地 SQLite 保存事件日志、目标、关系和权属约定；重要事件用可审计的摘要检索，暂不把向量数据库作为 MVP 前提。事件写入应幂等，并标记观察、推断或他人陈述。客户端桥接只传过滤后的观察和技能结果，不暴露全量世界真值给 LLM。

### 多层记忆，而非一个向量库

| 层 | 保存内容 | 何时读取/更新 |
| --- | --- | --- |
| 工作记忆 | 当前观察、危险、正在执行的技能、最近对话与尚未完成的约定 | 每次局部决策；短时过期 |
| 情节记忆 | 亲历事件、时间地点、参与者、证据来源、当时情绪与行动结果 | 事件到来时追加；社会判断时按人物和事件检索 |
| 语义/关系信念 | 从多次经历归纳的习惯、权属约定、地点认识与关系判断 | 有新证据时更新，并保留可追溯事件 |
| 程序/技能经验 | 某种操作在什么条件下成功或失败、失败原因 | 技能结果到来时学习；选择任务技能前查询 |
| 外部知识 | 检索到的教程、来源、适用游戏版本、获取时间及尚待实测的步骤 | 知识任务完成时记录；版本变更或实测矛盾时修订 |
| 预置世界书 | 原版生存常识及所选 Java 版本的公开机制，附来源/适用范围 | 在首登前按版本装载；规划或遇未知概念时按需读取，见[世界书](world-guide.md) |
| 自我叙事 | 人格倾向、长期目标、重要损失与成就的有限摘要 | 长程规划时使用；缓慢更新 |

不把所有记忆按相似度拼进提示词。先根据本次决策检索对应人物、地点、目标与可用技能，再结合重要度、时间、可靠性和反证选出少量相关材料。决定是否再次相信某人时，检索历次合作、侵占、道歉和赔偿；决定能否落地水时读取本地物品和技能配置，不能等待语义检索或模型返回。

每条长期记忆保留来源类型、`event_id`、观察时间、置信度、重要度、标签与有效性。高情绪冲击和长期目标相关的事件可以优先保留，但重要度不等于真实性：强烈怀疑仍是怀疑。时间衰减用于降低线索的当前可靠性，不抹除重要经历；旧摘要可以合并或归档，原始证据须能回查。新证据通过“修正/否定”关系连接旧信念，不能静默覆盖，也不能让一条错误检索结果立即改变长期身份。

### 决策闭环

`过滤后观察 → 带来源的事件 → 更新信念与情绪 → 产生/重排候选目标 → 按需检索记忆 → 选择意图 → 本地执行与抢占 → 记录结果 → 修正目标和技能经验`。

候选目标包括维持安全、推进自身计划、履行承诺、调查损失、回应别人，也可从亲历机会和角色兴趣中生出以前未列过的目标。LLM 可以解释复杂线索、提出新行动与生成交流方式；重大取舍与是否取消承诺由 Kin 决定，本地层只检查已选目标是否可执行、资源是否足够、信息是否过期，以及反射层是否已经抢占。一次未成功的调查或技能执行必须反馈失败，不可当成完成后写入“已经找到犯人”。决策责任见[自主权设计](decision-agency.md)。事件提取、摘要与检索可以试用较轻的后台模型，但其输出都要带出处并接受与原始事件的核对；当模型不可用时，保留原事件和未完成目标，不填造新的记忆。

未知任务可以触发独立的 `research` 目标：角色先承认不熟悉，记下与玩家达成的合作约定，委托外部工具查资料，待结果返回后评估来源、版本、材料与实际世界条件。查到教程不等于学会技能或完成建筑；只有经过讨论与游戏内试做的结果，才能沉淀为可复用的程序经验。检索资料期间仍由本地身体层处理危险和必要的生存动作。

在查询网络前先查看版本匹配的原版世界书：它为 Kin 提供基础游戏语言、合成/生存/进度常识和已整理的版本变化。世界书是“公开玩法知识”，不是 Kin 亲眼观察到的地图；若资料缺失、版本不符或操作结果冲突，才对具体问题发起外部查询，不能让旧攻略覆盖新的游戏事实。

社会判断不只是从信任分数输出“相信/不相信”。A 炫耀一箱钻石并自称开矿透时，角色分别记下自己实际见到什么、A 声称什么、公开服务器规则是否可核查、自己是否羡慕或受挫，再考虑接受、追问、举报、无视或主动开矿透等不同后果。若配置允许矿透，启用与关闭是角色的行动，矿点记忆标记来源；一条吹牛或一句“服主不管”不能自动开启能力。详见[社会判断](social-judgment.md)。

自主学习应区分情节记忆、可反驳的归纳信念、外部知识、候选方法和已验证程序经验。技能成功与失败都会反馈，能重复的流程才进入可复用技能目录；社会关系的经验仍是带证据的倾向，不自动成为报复脚本。晋级、失效与修订流程见[自主学习](learning.md)。
