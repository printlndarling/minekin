# 从出生到通关之后：单个 Kin 的玩家旅程

这是一份**体验检查与能力范围**，不是让每个 Kin 每天照着做的攻略。Kin 在原版 Java 生存世界里有自己的身份、喜好、当前资源、亲历地图、身体技能与承诺。初始默认主线是逐步发展、击败末影龙并回到主世界；想法不提供材料、战斗能力或对未知维度的知识。它可选择当前项目、安排推进主线的时机，并因世界经历、朋友关系或自身判断改变乃至放弃主线；不是等真人发布主线任务才开始生活。

| 玩家此刻可能遇到 | 自主选择的例子 | 必须有的可用身体/反馈 | 待验证而不能直接保证 |
| --- | --- | --- | --- |
| 首次出生与第一晚 | 找木头或食物；先找临时庇护、村庄、朋友或安静观察 | 发现合理可见目标，移动、采集、拾取、背包/合成、危险抢占 | 夜晚避险、食物补给、床和重生点的完整闭环 |
| 初期准备与日常 | 补工具、储木/煤、做炉子；等矿烧好或趁机另做事 | 盘点实际背包，判断材料前提，GUI 合成、熔炼、存取和结果检查 | 背包满、工具损坏、燃料不足、炉子/物品过期时能否发现并恢复 |
| 选择生活方式 | 搭家、找更满意地点、带床旅行、远行后搬迁 | 局部地形记忆、路径与返程、放置/施工、权属和地点复查 | 美观建筑的 3D 规划、按图逐步施工与修正不能从“知道建造知识”推断 |
| 生存战斗与成长 | 回避或试打怪物、练习技能、探索有挑战的地方 | 本地目标追踪、走位、攻防、撤退、伤害反馈；高层只能选战术目标 | PvE/PvP 动作控制、盾牌和移动目标的效果尚无原型证据 |
| 向下界与末地推进 | 根据主线和自己现阶段的利益备材料、建门、找所需资源；也可改变主意 | 自身装备与所知路线的前提判断，跨维度进出、返回、任务中断/复查 | 从第一天到击败末影龙的整个任务链远超首登原型；阶段技能逐项验证 |
| 击败末影龙之后 | 回到主世界，继续探索/建设/交友/挑战，或过平淡生活 | 确认游戏实际事件，关闭已完成目标并保留身份、经历及未完成承诺 | 不强制通关后二次挑战，也不把击败末影龙当项目结束或最终目标 |

## 可做、不可做与不用做

高层可提出“我以后想打末影龙”；任务层依据**这个 Kin 现在所知、所拥有及身体会做什么**，列出可执行的近期行动、缺前提的项目与竞争路线。若 Kin 选定制作某件工具且缺木板/木棍，采集或取得对应材料便成为完成该选定方案的前提；它仍可放弃做工具、使用现成工具、借物或换玩法。初登想马上穿钻石甲是当前不可执行的意图，不会变成无限循环的采钻命令。

任务图给计划可行性与失败反馈，不负责规定每个人格应每天拿什么装备、必须在哪天去下界或什么时候算“准备好了”。不想做的可选项目可以留在候选目标里，不因当天没有资源产出自动判为故障。紧急避险仍由本地层抢占；日常等待、犹豫、休息则是角色选择。反复无法到达、合成失败或不适用的教程需报告真实原因，高层可换路、求助、暂停或取消项目。

## 范围与后续调研

首个可运行演示的目标是一个 Kin **自己连续生活若干游戏日**：真实解决基本食物与第一晚生存，获得基础材料，形成并推进个人项目，能等候与休息，失败/死亡后保持身份并修订安排；社会互动能影响但不能替代它的生活。它开局有打龙的默认远期主线，仍可自定优先级或因经历改主线；路线图不得把“没打死龙”判为首版自治失败。后续扩展要分别验证更稳定的补给与夜晚策略、仓储与熔炼、施工、怪物战斗、跨维度返程以及末地目标的实际客户端技能，记录能否做、失败原因和替代路线。

测试应比较相同开局下不同人格的目标与取舍，也要比较同一 Kin 在材料不足、装备已有、任务中断和多次失败时的调整。按[开发路线](roadmap.md)回放的是能力和判断，不是预排剧情；知识、操作与主动学习分别由[世界书](world-guide.md)、[实战技能](ability.md)和[自主学习](learning.md)支撑。
