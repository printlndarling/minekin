# 导航转向后的移动前复核

基线 `8798cf5`。`move_to` 等待转向完成后仍使用转向前的位置：转向期间角色已到达目的地，或位置字段已缺失，仍会按下前进键。两项新回归在修前失败。

执行器现在在前进前读取最新观察，复核观察存在、世界代际、GUI 和位置。已经到达时由该读数确认，移动步数为零；位置缺失时按名 `MOVE_POSITION_UNKNOWN` 拒绝。若位移改变目标方向，重新瞄准后再检查；耗尽截止时间不再发送新的移动输入。受阻跳跃与到达确认保持原有有界机制。

验证：三项新回归覆盖转向中到达、位置缺失、位移后的再次瞄准。技能、计划和自主循环三组 **244 passed**，ruff、格式和 pyright 通过。这是受控测试读数，不是真实模型或 Minecraft 活体证明。
