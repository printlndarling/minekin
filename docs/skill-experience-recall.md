# 跨会话技能经历检索

`adapters/sqlite/skill_history.py` 直接读同 Kin 的持久事件账本；已有 `mind_for_run → session_history → DecisionRequest` 接线将结果送入模型。无新数据库、迁移或历史改写。

## 当前能力

- 最近 64 条可信 `SkillStepRecorded` 为扫描窗口，另外读一条判断是否仍有更老记录；当前 run 与其他 Kin 排除。
- 保留最近 8 条详细记录；另给最多 8 个技能的窗口内结果/原因计数和每种结果的最新事件引用。成功、失败、中断、未知分别保留，不计算终身成功率。
- 每条扫描记录先验 payload 摘要和字段边界。扫描内坏记录使整个包拒绝，不能只挑较新的成功遮盖反证。
- 包的 UTF-8 JSON 上限 16 KiB。省略的记录/技能摘要和扫描外历史明确标注，不声称已检索所有过去。
- 来源与历史标签保留；世界和版本适用性仍为 unknown。旧库存、坐标、参数、目标和模型原文不送入本包。记录不是命令，不恢复旧输入，不自动禁用技能。

## 验证与剩余范围

`tests/unit/test_skill_history.py` 覆盖重启读回、身份/信任隔离、失败被后续转向挤出后的聚合、矛盾结果引用、预算截断、坏摘要拒绝，以及实际 PlayerMind 请求携带摘要但不恢复动作。请求测试使用捕获提供方，不是真实 LLM 或游戏验收。

这是 S5 的技能经历增量，不是完整长期记忆：人物/地点/承诺检索、世界与版本适用性、信念修订、人格心境变化及真实模型受经历影响的对照仍需推进。摘要计数仅说明软件曾记录的结果，不能证明未来成功。
