# 游戏能力：起点、动作掌握与成长

人格决定 Kin 想怎样玩，游戏能力决定它**现在做得到什么**。世界书提供公开玩法常识，已有技能库提供方法，而角色熟练度决定其能否在真实压力和资源条件下完成。了解落地水机制、背包里有水桶、能操作客户端、自己掌握落地水，是四个不同条件。

## 创建时的能力选项

首次创建 Kin 时可分别选择人格和初始能力。能力以**多领域轮廓（能力多边形）**呈现：可为各方向单独设定起点，或全部留空随机生成一张有长短板的轮廓；持久保存配置与随机种子，重启不重新抽取。不把“萌新／普通／熟手”当成决定所有能力的单一等级，也不要求各方向分数总和恒定。像真人一样，Kin 可以很会盖房又总在 PvP 输，或善于保命却不爱探险。

## 顶层领域与子技能（待原型校准）

下列九个方向是**便于创建角色、展示能力多边形和讨论取舍的初稿**，不是九个万能数值。实际操作依赖具体子技能、游戏版本与场景；子技能可以跨方向组合，一次成功也不应同时升级整个领域。

| 领域 | 典型子技能 | 可区分的差异 |
| --- | --- | --- |
| 生存应变 | 危险察觉、食物/血量管理、跌落/火/岩浆求生、临时避险 | 会提前避险不等于会落地水 |
| PvE 战斗 | 怪物习性、近远战、撤退、装备选择、多人打怪 | 会杀怪不等于擅长 PvP |
| PvP 对抗 | 对玩家走位、攻防、节奏判断、追逃与资源权衡 | 对真人玩家的博弈和打怪分开验证 |
| 探索与移动 | 找路、地形观察、探索补给、穿越复杂环境、维度旅行 | 地图记忆、攀爬与冒险勇气各自独立 |
| 采集与资源获取 | 采矿路线、伐木、种植、狩猎、资源发现与回收 | 有矿透等特殊感知不自动提高采集手法 |
| 建造 | 结构规划、美感、空间利用、放置施工、改造与修补 | 施工准确、建筑审美和选材不一定相同 |
| 红石与机制 | 红石电路、刷怪条件、农场自动化、机制诊断 | 看懂教程不代表能设计和排错 |
| 制作与物资管理 | 合成、熔炼、装备升级、分类仓储、材料规划 | 快速合成与跨日物资计划不同 |
| 协作与沟通 | 分工、共同施工、说明方案、协商交易、教与学 | 会沟通是能力；愿不愿帮人是人格与关系 |

高压实时操作还横跨多个领域，如反应窗口、瞄准、选取快捷栏和中断恢复；不能把它们塞进一个泛用“操作高手”总分。角色的**游玩偏好**也不是能力：爱速通却缺乏战斗技巧的 Kin 可能因挫败而练习、找朋友帮忙或改变目标。各领域起点可以通过文字描述和单项调整表达，随机生成也允许不均衡轮廓；具体轴数和粒度待真实演示检验，若两个轴总在测同一件事就合并，若一轴掩盖显著差异就拆子技能。

| 要素 | 用处 | 不等于 |
| --- | --- | --- |
| 基本常识 | 知道方块、物品和常见策略 | 在操作上已掌握 |
| 方法知识 | 知道步骤、前提和检查方式 | 每次都能实时执行 |
| 动作掌握 | 反应、选物、转视角、手眼协调和压力下的稳定性 | 永不失误或拥有装备 |
| 可用资源 | 装备、快捷栏、水桶、时间窗口和当前位置 | 个体技能水平 |

**落地水不是默认通用技能**。若 Kin 不会它，即使世界书知道这项技巧，也不会把“完美落地水”安装为每个角色的反射；可以尝试求生、提前回避悬崖或用已掌握的替代办法。熟手可尝试落地水，仍受能否切到水桶、落点是否合理、受击时的惊慌、服务器时延等影响。基础紧急控制可以保持避险和合法求生，但不承诺每个 Kin 能作出同样高阶动作。

一项动作技能可记录学习阶段（不了解／知道但未练／练习中／相对熟练）、适用条件、亲历训练次数、成功和失败证据、反应窗口与典型误差。阶段不是固定命中率，动作在不同高度、装备、延迟和压力下表现不同；避免用随意抽签强行制造“人味”，也不能利用精确客户端数据达到超出角色能力的完美成功。行为层选择技能前检查自己是否掌握及当前物品/环境条件，本地控制器根据角色动作配置执行与回报。

## 自主成长

Kin 可以主动练习、请人演示、查教程、试做、复盘并改进，但查到攻略不会自动升级动作掌握。成长需来自可核验的尝试和反例：不同条件下反复完成才提高熟练范围；条件变了就缩小把握，连续失败也可让它暂时放弃或重新练习。进度不应只奖“成功次数”：识别危险而选择安全路线、练习失败后发现水桶不在快捷栏，也属于能力学习。操作能力与[自主学习的程序经验](learning.md)相互关联，但人格偏好、关系和情绪仍分别维护。

验收方向：同一出生条件下对不同战斗/落地水起点回放怪物攻击、紧急跌落和低装备生存；检查动作选择、真实失败、解释及经验成长是否连续。更高难度不得仅靠一句高手人设或人为固定胜率代替操作验证。
