# 游戏能力：起点、动作掌握与成长

人格决定 Kin 想怎样玩，游戏能力决定它**现在做得到什么**。世界书提供公开玩法常识，已有技能库提供方法，而角色熟练度决定其能否在真实压力和资源条件下完成。了解落地水机制、背包里有水桶、能操作客户端、自己掌握落地水，是四个不同条件。

## 创建时的能力选项

首次创建 Kin 时可分别选择人格和初始能力。能力提供“萌新／普通／熟手”等简易起点、可单项自定义，也可留空随机生成；持久保存配置与随机种子，重启不重新抽能力。具体能力应按任务而非笼统“游戏水平”定义，例如基础生存、战斗、探索、导航、挖矿采集、合成/熔炼、建造/红石、资源规划、交流协作。熟练战斗的人也可能不会做刷怪塔，萌新也可能善于建筑。

| 要素 | 用处 | 不等于 |
| --- | --- | --- |
| 基本常识 | 知道方块、物品和常见策略 | 在操作上已掌握 |
| 方法知识 | 知道步骤、前提和检查方式 | 每次都能实时执行 |
| 动作掌握 | 反应、选物、转视角、手眼协调和压力下的稳定性 | 永不失误或拥有装备 |
| 可用资源 | 装备、快捷栏、水桶、时间窗口和当前位置 | 个体技能水平 |

**落地水不是默认通用技能**。若 Kin 不会它，即使世界书知道这项技巧，也不会把“完美落地水”安装为每个角色的反射；可以尝试求生、提前回避悬崖或用已掌握的替代办法。熟手可尝试落地水，仍受能否切到水桶、落点是否合理、受击时的惊慌、服务器时延等影响。基础紧急控制可以保持避险和合法求生，但不承诺每个 Kin 能作出同样高阶动作。

一项动作技能可记录学习阶段（不了解／知道但未练／练习中／相对熟练）、适用条件、亲历训练次数、成功和失败证据、反应窗口与典型误差。阶段不是固定命中率，动作在不同高度、装备、延迟和压力下表现不同；避免用随意抽签强行制造“人味”，也不能利用精确客户端数据达到超出角色能力的完美成功。行为层选择技能前检查自己是否掌握及当前物品/环境条件，本地控制器根据角色动作配置执行与回报。

## 自主成长

Kin 可以主动练习、请人演示、查教程、试做、复盘并改进，但查到攻略不会自动升级动作掌握。成长需来自可核验的尝试和反例：不同条件下反复完成才提高熟练范围；条件变了就缩小把握，连续失败也可让它暂时放弃或重新练习。进度不应只奖“成功次数”：识别危险而选择安全路线、练习失败后发现水桶不在快捷栏，也属于能力学习。操作能力与[自主学习的程序经验](learning.md)相互关联，但人格偏好、关系和情绪仍分别维护。

验收方向：同一出生条件下对不同战斗/落地水起点回放怪物攻击、紧急跌落和低装备生存；检查动作选择、真实失败、解释及经验成长是否连续。更高难度不得仅靠一句高手人设或人为固定胜率代替操作验证。
