# 实际技能：入世后的尝试与成长

[领域知识掌握多边形](knowledge-profile.md)只规定 Kin 开局知道多少公开玩法，**不规定它玩得多好**。它可以熟知通关路线，却因走位和装备判断失误迟迟通不了关；可以读懂红石教程，却在自己盖的电路上反复接错线。真实技能要从 Kin 的亲历尝试、失败、复盘与复用中形成，不能由初始领域知识深度直接换算。

| 状态 | 例子 | 怎样确定 |
| --- | --- | --- |
| 已有知识 | 知道落地水的步骤和适用条件 | 世界书、预置知识树或带来源的查询 |
| 候选方法 | 计划用水桶救跌落、按教程接线 | 有可执行前提、步骤及失败检查，仍可能未经自己试过 |
| 操作经历 | 实际切水桶、转视角、使用；接线并测试 | 客户端合法输入和真实游戏结果，可中断或失败 |
| 个人掌握 | 在记录的条件下曾多次做成，知道自己常在哪一步失误 | 可回放事件、训练范围和反例；不推广到所有环境 |

Kin 刚进世界有最基本的客户端行动能力：移动、打开背包、交互等动作能否完成需由底座验证；**默认不把所有高阶技巧装成它已熟练掌握的技能**。知道落地水不等于有水桶在快捷栏，不等于能及时选择和瞄准；它可以在第一次跌落时尝试，若角色尚未练过，应承认这是一次冒险尝试，不能靠精确状态读取制造“多年水桶高手”的表现。若不能尝试，先做它能做的局部避险；本地安全动作不等待 LLM。

真实能力应针对具体任务和条件记录，不沿用九个知识轴作成功率。某项动作可记录 `task`、版本、工具、执行控制器、观察和结果、失败原因、适用条件、反应窗口、训练阶段（未试/尝试过/在部分条件下熟练）与复查时间。红石实例则记录能否独立设计、材料准备、施工、运行测试及排错；不同实例的经验不能无条件共用。角色表现受装备、危险、注意力、网络和当前世界规则影响，避免用一个固定掷骰胜率假装技术实现。

Kin 可主动练习、请人示范、查教程、试做、复盘并改进。一次正确回答不升级施工熟练度；一次失败也不证明永远没能力。成功与反例共同调整它对**自己能否做到**的信念，新的任务再检查条件，必要时练习、求助、改变方案或放弃；见[自主学习闭环](learning.md)。现实中“懂很多却很菜”的表现由这种知识/实际结果的不一致自然产生，不要求大模型故意装不懂或故意答错。

验收方向：给两个 Kin 同样高的通关知识、相同起始装备，不预设其实战胜率；记录多次怪物对抗、逃跑、失误和自我调整。再给红石高知识 Kin 一张其未试过的复杂线路，检查从提出方案到真实施工/测试之间是否明确区分“知道”与“做到了”。
