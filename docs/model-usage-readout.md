# 模型调用与预算读数

2026-10-04 增量：替代旧只读契约中 `modelCost`“恒为 not_wired”的现在时声明；快照字段形状与路由不变，`modelConfig` 仍是独立缺口。

自主会话每完成一个技能步，由 Core 把当时 `CostLedger` 的累计计数写入同一 `SkillStepRecorded.model_usage`。Gateway 只投影最近技能步自己的字段：调用次数、估算微单位/该运行预算、预算拒绝次数、usage 不完整的调用次数和计算费率。它不从其他步骤、其他运行或当前配置补造数值，不读取模型名称、地址、密钥或供应商响应原文。

这些是**截至该技能步的账本估算**，不是正在等待中的调用计数，也不是供应商账单。供应商缺少 token usage 时明确显示“不完整”，不能据估算零值说免费。预算单位沿用运行者配置，不擅自换算为人民币或美元。

旧台账行没有字段时仍显示 `not_wired`；畸形、新字段带非 allowlist 成员或数值不合法时显示 `unknown`，不当作零花费。脚本动作和尚无技能步的运行不被补造模型账本。

验证：`test_model_usage_totals.py` 的真实 SQLite 台账→Gateway 投影、成本账本单测、前端技能步组件及会话回归；此增量尚未取得新 JVM/真实模型/浏览器活体读数。
