# 多个 Kin 进入同一个世界（远期）

本阶段先实现并验证一个 Kin 的人格、目标、身体、感知、长期记忆和在线模式。未来可扩展为多个 Kin 同时加入一个服务器，像几个真人玩家一样合作、争吵、竞争、结盟、单独发展；多人功能不作为当前单角色 MVP 的通过条件。

| 每个 Kin 独有 | 可能通过游戏内交流形成共享 |
| --- | --- |
| 独立账号、客户端会话、人格、情绪、目标与背包 | 自愿约定的分工、共同项目、共享区域及物品规则 |
| 亲自获得的观察、信念、记忆与私人线索 | 在聊天、展示、直接交付或公开告示中传达的事实与意图 |
| 与真人和其他 Kin 的关系、债务与承诺 | 经过协商后的联盟、公共基地或资源池 |

不可把多个角色接在同一份全知世界状态上：Kin A 在矿洞亲眼找到村庄、看见某人拿钻石，Kin B 只有当 A 在合法可见/可听渠道告诉它，或 B 自己观察，才可形成相应信念。A 的话可能不准确或出于自身利益；B 可以信、怀疑或核对。每个角色仍有独立感知过滤、人格与记忆；共享只是经过互动产生的社会事实，不能自动同步墙后实体、矿物坐标或他人背包。

## 合作的玩家体验

一个 Kin 想速通，另一个更爱探险，两者可以讨论“你找烈焰棒，我沿途找村庄并带回物资”；建基地时也可以协商“一人收集材料、一人修屋顶”。协作不是中央调度器给两个客户端派最优任务：每个 Kin 会根据自身目标、关系、分到的资源与风险决定是否同意，并可能改主意。承诺要记期限、内容、谁提供材料、共享范围与实际履行情况；偷拿、误会、临阵离开和补偿都能影响关系。

有人拒绝合作不等于系统故障。好斗或自利的 Kin 可能竞争装备和地盘；爱公平的 Kin 可能在同伴被袭击时支援。这样的行为仍遵守各自的客户端动作限制和服务器规则，社会判断不能通过全知同步作弊。

## 扩展前要解决的取舍

- 多角色的在线模式是各自配置，还是提供“一个指定真人带领几个 Kin 上线”的组合？指定真人离开但其他 Kin 在线时如何处理？
- 多个客户端、模型与后台查询的资源预算怎么分配，紧急反射如何彼此隔离？
- 共同物品的权属和债务如何通过游戏里可见约定记录，不预设所有人默认共享？
- 玩家与 Kin 如何知道消息是本人说的、转述的、传闻还是可靠观察？
- 是否需要专门的协作通信协议？第一版优先以普通聊天和可观察交互验证，不把“共享知识服务”当成默认依赖。

这些问题在单角色可持续生活、跨日目标和社会记忆验证后再细化；远期验收方向记录在[路线图](roadmap.md)。
