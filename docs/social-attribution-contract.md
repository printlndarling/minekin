# 单 Kin 伤害与失物归因：身体信号不能洗成目击证据

2026-09-16 静态核查 Java 1.21.4 / Yarn `1.21.4+build.8`，无真实同服抢占/击退/死亡回放。此页落实[交互注意/意图](attention-intent.md)、[感知边界](perception-implementation.md)与[心智数据契约](mind-data-contract.md)；**不写“受击=敌意”“箱子少了=某玩家偷的”的行为模板**。

## 原版接口给了什么，Kin 实际能说知道什么

同版[`EntityDamageS2CPacket`](https://maven.fabricmc.net/docs/yarn-1.21.4%2Bbuild.8/net/minecraft/network/packet/s2c/play/EntityDamageS2CPacket.html)列受击实体 ID、伤害类型、`sourceCauseId/sourceDirectId` 与可选来源位置，并可在当前 world `createDamageSource`；[`ClientPlayNetworkHandler.onEntityDamage`](https://maven.fabricmc.net/docs/yarn-1.21.4%2Bbuild.8/net/minecraft/client/network/ClientPlayNetworkHandler.html)是该包候选接入点；[`DamageSource.getAttacker/getSource`](https://maven.fabricmc.net/docs/yarn-1.21.4%2Bbuild.8/net/minecraft/entity/damage/DamageSource.html)可能返回实体，也可能为空。**接口签名不证明每次受击有正确玩家 ID、事件及时到达，或 Kin 肉眼听觉知道攻击者是谁**。当服务端因投射物/环境/边界条件传了因果实体 ID，但攻击者藏在墙后/视锥外时，把该身份直接送给 PlayerMind 就是借协议元数据做穿墙归因；即使能触发本地 `DAMAGE` 风险信号，也不能自动创建“亲眼见 Steve 打我”的社会事实。

| 分层记录 | 来源与使用权 | 会产生什么，不会产生什么 |
| --- | --- | --- |
| `PhysicalDamageEvent`：本人血量变化/受击、击退、下落 | 本人 HUD/触觉与客户端状态，本地反射优先消费；包中的伤害因果元数据先留在**限权诊断/评测通道**，在线普通模式默认不给人物名 | 能立刻举盾、撤离、求生；不需等 LLM，也不判恶意。坠崖后即使一次打击就保命 |
| `SocialCue`：看见一名玩家挥手与击中、实际听见的声响/聊天、死亡画面/亲历旧冲突 | 玩家可感知过滤后带 `observed_tick/actor_id/visible_or_audio/confidence` 的事件 | 能提出“可能是 A”“B 刚才叫我”的解释；发言只证明对方说了话，不证明其诚实或服主规则 |
| `Hypothesis`：谁造成、是否蓄意/提醒/误伤、失物去了哪里 | 链接可见线索、反证、过期状态与社交背景；可有竞争解释（失物被拿、自己放错/给过别人、服务器变化） | 只是 Kin 的推断，概率高也不等于看见过程。不能仅因有人在线或曾在几千格外就拿服务端真值补坐标 |
| `EvaluationTrace`：服务端测试世界真值与原始网络元数据 | 私人测试服离线隔离；不让线上规划器/记忆/自动目标读取 | 可算指认正确率、错怪/漏怪和源数据影响；不是 Kin 自己的记忆 |

首版默认作**保守但不圣母的来源管控**：本人受伤是已知事实；被打时看见谁打/明确听到可识别线索可形成有证据的归因；屏幕看不见但包内部关联某实体，只能在本地紧急诊断使用伤害级别/因果类型，且需先评估是不是玩家本来就可通过死亡画面、音效、方向或其他 UI 感知，**不静默揭示画外精确身份与位置**。若场景本身有游戏内死亡文字标出某人，那条文字是玩家可见证据，须记录其实际出现时间；不能提前使用未来死亡画面的信息。服务器日志、管理员归档、未打开容器以及近处其它玩家此刻精确位置均不可作为普通模式归因入口。

## 无法观察到全过程时，关系与选择仍是 Kin 自主

“回来发现 3 钻石不见”需先有 Kin **确实打开**自己箱子时的旧快照、再实际打开同一箱子得到新可观察库存；失去的数量也可能因自己放错或拿走。原版客户端对未在场的取物行为没有可靠自动录像：**不能声称存在默认可复用的“谁开箱/谁拿钻石”证据**，自己家所有权也要按放置、约定或观察保存。只有自己与 A 同世界、或 A 曾被亲眼看到在家附近、或 B 曾被亲眼看见在远处，才可根据那些**有时间与置信度的可感知历史**推理；没有可靠独立信息时“必然 A 偷”仍属强烈猜测，不在数据库改为目击事实。Kin 可以问玩家、观察之后的行为、要求归还/补偿、设局调查或干脆放弃；公开渠道必须在目标服允许、外部查询不能越权。

即使不知道是谁，也可沮丧、烦躁、换箱子、休息、迁怒或为了找回物资主动重设目标；是否指控、报复、攻击无辜者、陷阱、和解由 Kin 人格、失物价值、实力、已有关系、风险和**世界外服务器实际准入/服规**共同约束，不是固定“证据不到 X 就必须温柔”。坏脾气 Kin 可以“我怀疑你，所以我来追问/揍你”，但不能骗自己的信念账本说“我亲眼看到了”；这种区分同时允许失误、恶作剧、错误指责及之后反证纠正。最初新手空手死亡与装备丰富后死亡的找回价值不同，Kin 自己权衡，复活仍是同一人物。

阶段 0 两人/三人私人测试回放：专心合成被朋友轻打提醒；残血一击致死；被墙后玩家/弓箭/怪物打；被悬崖击退而受击者没看到攻击者；A 在 Kin 亲历地图近处但 B 远处；两人都没有位置证据；玩家撒谎/坦白/归还。对照自己屏幕/聊天/声音/过去已观察记录、网络元数据与测试服隔离真值，逐项记录受击触发→本地首次救援、`visible_attacker` 与 `packet_cause_id` 是否不同、失物旧/新箱 GUI 同步、Kin 猜测来源/反证、指认准确与错怪、关系纠正和行动自主性。**不得用原始包 ID 给上层开 360°探测，再在 Demo 里宣称 Kin 像正常玩家。**
