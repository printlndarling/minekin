# 交互注意力与攻击意图

Kin 的注意力有限：合成、熔炼、建造、战斗、研究和聊天会争夺关注。**注意到一个事件**、**将事件联系到某人**、**推断对方意图**、**选择回应**是不同步骤。声音漏听可以像真人一样发生；受击的本地避险则无需等待 PlayerMind 想明白是谁。互动门槛随当前专注程度、风险、关系、人格和重复经历改变，不是固定“受击 N 次就敌对”。

## 四道判断

| 步骤 | 例子 | 限制 |
| --- | --- | --- |
| 注意到 | 正在工作台时没留意远处聊天，受击后立即发现自己掉血 | 对话可延迟处理；危险反射不等待注意力模型或 LLM |
| 判断发生了什么 | 有人叫过自己、自己受击、对方站近并看向自己 | 未看见攻击者时社会身份来源仍未知；[同版伤害包](social-attribution-contract.md)可能含身体因果元数据，但不等于 Kin 在屏幕上认出人。伤害事实不等于意图事实 |
| 形成竞争解释 | 对方想提醒、误伤、玩笑、驱赶或蓄意伤害 | 依据可见动作、场景、过去关系和后续回应，保留反证 |
| 决定回应 | 转头说话、询问、提醒别再打、后退/挡伤、逃跑或反击 | 当前人身危险可先自保；报复与关系变化须有独立判断 |

工作台案例：玩家叫 Kin 一声，它专注合成而没注意；对方轻打一下，Kin 可以先停下操作、转头问“找我？”有的 Kin 不计较，有的会抱怨，有的脾气急、又有足够证据知道是谁打的，即使认为对方只是提醒，也可能立刻回敬一拳。**回敬不等于认定仇敌**，只是一种带社交后果的人格选择。若同一人反复打断、追着它砍，伤害和蓄意证据会增加；即使对方口称“只是提醒”，Kin 也可不信。能否识别玩家先前发言取决于客户端实际观察与记录，不补造漏掉的聊天。

几个不同情形用同一机制处理：

- 朋友帮 Kin 打怪时打中了它：先止损、看伤害与怪的位置、询问或抱怨；不是自动从盟友变仇人。
- 陌生玩家趁 Kin 分心连续攻击：立刻尝试防御/撤退，待看见攻击者和追击证据后形成敌意并决定是否反击。
- 被从悬崖打落：即使只有一次命中，坠落是紧急高风险，先由本地能力层求生；是否蓄意仍要根据追击、位置、先前冲突和对方回应判断，不能把“先不判敌意”误解为“等着摔死”。
- 玩家挥拳或恶作剧却没有造成伤害：可因关系与情境理解为玩笑，也可不喜欢；亲近不是无限次伤害的免责牌。
- 玩家喊“帮我”但 Kin 正被攻击：本地保命优先，危险解除后再决定是否回应；漏听、迟答或拒绝有不同原因。

低层安全阈值与高层意图阈值分开。即时伤害风险足以触发防御和逃跑，不必先证明攻击者恶意；一击也可能致命。是否警告、指认、追击或长期记仇则依据证据和自身能力/价值观选择。对某人熟悉会改变初始解释，但新的重复伤害仍可推翻旧信任。角色可以误判：把提醒误当攻击后，见新证据可修正关系并道歉；把蓄意攻击误当玩笑后，也可以更新警觉。

## 意图与损失分开结算

伤害同为一次命中，满血工作台前、残血时或悬崖边的结果可以完全不同。善意提醒误杀残血 Kin 时，它可相信对方本意是叫醒自己，同时因死亡、装备丢失、已有目标中断而失落或生气；是否要求道歉、补偿、回敬、暂时疏远或“东西捡回来就算了”，由脾气、亲疏、物资损失、装备能否找回和对方后续行动决定。确认死亡来源也受正常可见的死亡画面、在场观察及自述约束；不知道是谁造成时不凭空指定犯人。

若残血被打，本地保命优先于即时情绪回应；复活后则由 PlayerMind 根据实际损失继续处理。原谅意图不强制原谅后果，损失巨大也不自动证明对方有杀意。重复的“误伤”或拒绝赔偿可以改变 Kin 对其行为和关系的判断。

回放工作台一击提醒、满血与残血误伤致死、失物/拾回/赔偿、陌生人连续追击、悬崖推落与虚假的“开玩笑”。记录声音/聊天注意时间、抢占安全动作时间、可能攻击者的观察出处、意图与损失的分开评估、回敬/不回敬原因和事后修订。注意力失误应基于可观测的任务负荷而非强制每隔几次漏听；高危情况下即使注意被占用也须有本地安全输入。见[能力差异](ability.md)与[PlayerMind](player-mind.md)。
