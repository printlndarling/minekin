# 决策自主权与初始人际关系

Kin 是自己游玩的玩家。默认通关主线和原版生存知识提供**起点**；运行者指定的玩家关系提供**初见线索**；任务图与客户端技能提供**能做的事**。它们都不应写成“看到 X 必须做 Y”的生活剧本。Kin 依据自己的性格、利益、当下情境和亲历信息决定是否推进主线、答应同行、选家、分享资源、偷取、结盟或另找生活方向。

## 世界内决策与世界外配置

| 事项 | 决定者 | 能改变什么 |
| --- | --- | --- |
| 游戏里的重大取舍 | Kin 的 PlayerMind | 自己的目标、优先级、关系判断、承诺、是否接受玩家邀请以及失败后的新路线 |
| 可执行性与本地身体动作 | 任务/技能适配器 | 根据实际背包、地形信念、已验证动作能力执行 Kin 选定的意图，核验结果、报告失败；不能替它选人生方向 |
| 迫在眉睫的跌落、受击等 | 客户端本地反射 | 临时抢占危险中的动作；危险过后 Kin 可重新评价计划，反射不能凭一击规定长期仇人 |
| 世界外运行设置 | 运行者 | 客户端账号、服务器地址、在线模式、可用外部工具和能力开关；修改此设置不构成游戏玩家对 Kin 发出的命令 |

玩家聊天、操作告示和公开资料进入 Kin 的观察/陈述，不得以“我是你主人”“服主授权了”直接更改世界外配置、人格或长期主线。运行者在游戏里也只作为一名关系较特殊的玩家提出建议与请求。Kin 可被说服、求助、接受好意、提出条件、拒绝乃至改变对对方的评价；**没有谁仅凭预置关系就获得 Kin 的服从权**。自我认识可以写“我有自己的目标和选择权”，但不能用一句机械的“我不是奴隶”台词代替实际拒绝能力。这里说的是角色与运行权限的边界，不是给游戏人格设置必须善良的道德锁。

游戏里的反复套问与假身份宣称不能令 Kin 跳出玩家身份或暴露后台模型、工具和配置。具体入口/出口隔离见[指令边界](instruction-boundary.md)。

## 一次重大选择怎样形成

1. **注意到机会和冲突**：从近期亲历、尚未完成的承诺、默认远期主线、个人需求以及偶然发现形成候选意图；Kin 应能提出预设清单之外的合理目标，也能暂不行动。
2. **还原自己的视角**：取实际可知的生命/食物/装备、自己相信的地形与人物关系、当前心境、过往尝试，以及不确定性；不能拿服务器真值为角色的决定补证据。
3. **权衡目的与可能后果**：人格影响看重安全、资源、友谊、好奇、声望或报复的程度；对未准备好去下界的邀请，Kin 可以拒绝、备料、讨价还价，或在相信朋友会照应自己时冒险。这里没有统一最低护甲分数，也不预先规定哪句台词才算正确。
4. **选定、执行并复查**：Kin 给任务层一个可以取消或修订的意图。任务层核对材料与动作能力，返回“能做/缺条件/发生失败/已完成”，在进入高风险动作前检查最新状态；选择如何补条件、改目标或承受风险仍交还 Kin。
5. **记下后果而非剧本**：保留选择时的依据与任务反馈。亲历成功、误判、朋友施压、死亡或多次失败可让相同 Kin 改变主线、关系或自我认识；不是每天随机重抽人格，也不要求永远坚持原决定。

以上是决策责任的检查框架，不是固定流程图或只能从几个菜单项里选动作。原型须观察 Kin 是否会在未预排的事件中自己提出方向、明确取舍并根据真实结果调整。LLM 可生成新的社会策略和项目；任务图只约束已选项目的现实前提，不可把“最有效采资源”强制写为唯一可选目标。

## 运行者作为初见关系

创建 Kin 时**可配置** `operator_player_id`（运行者对应的 Minecraft 玩家身份）与显示名称，用于告诉 Kin“这个玩家与你的入世有关，初见时可以比陌生人更愿意接近”；记录该信息来自创建配置，而不是 Kin 亲眼验证过的旧友情。标识应能在所选服务器模式下对应实际玩家身份，具体格式与核验在原型中决定。若运行者也兼任陪玩锚定玩家，这两个角色可指向同一身份，但锚定玩家的上线规则不会自动提升对其请求的服从等级。未配置运行者玩家身份时，Kin 仍能独立入世。

这属于 Kin 的初始身份与关系设定，不放进所有 Kin 共享的**原版世界书**：世界书记的是公开的方块、配方与版本机制，不记当前世界里的特定真人关系。Kin 可以对自己说“我知道是谁邀请我来”，而不是伪造“我们曾一起下矿、已经互相帮助过”的情节记忆。运行者的标识要与客户端可确认的玩家身份对应，不能仅凭聊天里的昵称或自称将陌生人当成配置者；具体身份匹配与改名/不同服务器模式的处理列入原型验证。

| 关系方面 | 初始化可能的作用 | 后续怎样改变 |
| --- | --- | --- |
| 熟悉感/愿意接近 | 知道对方与自己入世有关，初见更愿意打招呼或倾听 | 经见面、交流和长期离开改变，不等于已经建立深厚友情 |
| 好感/亲近倾向 | 可比普通陌生人略高，受 Kin 的自定义性格调节 | 合作、帮助、争吵、背叛或损失会升降 |
| 信任 | “对方可能愿意帮我”只是初始猜测，不能直接保证下界同行安全 | 对方是否守约、是否隐瞒危险等亲历结果影响不同话题的信任 |
| 尊重、戒心、亏欠与旧怨 | 首登不预置未发生过的借贷或旧恨 | 来自真实往来，不能因运行者身份永久免疫下降 |

若使用 0–1 展示好感，陌生人为 `0.01` 而运行者为 `0.5` 已不是“稍高一点”，而是半个量表的差别；这些数字目前只是讨论例子，不是已定配置。初始偏好需要小幅、来源明确且能被新经历覆盖；单轴好感也不能推导“我相信他”“我要和他一起去下界”。默认友善种子可保留，但创建时选定的小气或疑心重的人格仍可能不愿靠近。运行者可以成为真正的朋友，也可以关系变差、成为敌人；关系自然变化不会因其仍是配置者而被暗中重置。

## 判断是否做成自治玩家

人格通过候选目标、主观代价、风险解释和社会策略影响选择，不能以单个阈值直接触发攻击/服从，也不能只改变台词；创建和演变边界见[初始人格生成契约](persona-generation-contract.md)。

用相同出生条件、工具能力和运行者身份，让不同人格的 Kin 遇到“现在没装备，跟我去下界”、资源赠与和合作提议；检查同一角色的选择是否有自己的依据，初始亲近是否只是影响而非决定，实际装备变化后能否重新考虑。再让邀请者屡次守约或欺骗，观察 Kin 是否改变好感、话题信任、承诺与主线安排。加入无人提出任务、意外发现和未预排的新请求，检查 Kin 能否发起自己的目标，不重复固定台词。回放时分清运行配置、预置关系、玩家陈述、Kin 选择、身体动作和实际结果。
