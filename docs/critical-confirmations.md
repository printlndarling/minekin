# 重大待确认清单

更新：2026-09-17。

## 当前状态

**无开放的重大待确认项。**

现有未定事项均属于固定产品方向下的实现参数、体验校准或真实原型结果，已由各专项契约给出默认值、失败回退与验收方法；它们不需要在开始 W00 前再次询问用户。

## 什么情况才进入本文件

只有会改变下列任一根本方向的问题才算重大确认：

1. 是否放弃真实 Minecraft Java 客户端身体，改用协议 Bot；
2. 是否把产品从独立 Harness 改成以 Mod 为产品本体；
3. 是否把 Microsoft/Xbox 正版认证改成默认前置；
4. 是否放弃玩家等价感知，默认开放隐藏世界真值或服务端特权；
5. 是否把 Kin 改成服从运行者的工具，而不是有拒绝权的自主玩家；
6. 是否把多 Kin、模组或多版本提前为首版主线，从而重写单 Kin P0；
7. 是否允许游戏聊天/网页修改可信配置、权限或身份；
8. 是否更改持久人格/记忆与多世界隔离的基本语义；
9. 是否公开发布会触发新的许可、账号、隐私或服务器合规风险，但现有方案没有可接受回退；
10. P0 实测证明全部有限候选失败，继续必须更换核心身体、认证、感知或进程架构。

以下不进入本文件：队列大小、超时、具体库、默认阈值、UI 字段布局、模型选择、日志保留天数、测试夹具以及能够保持架构不变的实现替代。此类事项由维护者依据证据自行决断并记录在对应契约或 research tracker。

## 关闭规则

重大项必须包含：

- 明确且互斥的选项；
- 每项的证据、成本、不可逆后果和对既有文档的影响；
- 推荐选项；
- 在等待确认期间仍可继续的工作；
- 用户确认与落实 commit。

在出现符合条件的问题前，本文件保持空清单，不能把普通工程参数包装成需要用户反复拍板的“大决定”。
