# 从聊天到记忆、网页与技能：权限不能沿内容传递

核对 2026-09-16；依据 [OWASP 原始提示词注入防护指南](https://cheatsheetseries.owasp.org/cheatsheets/LLM_Prompt_Injection_Prevention_Cheat_Sheet.html)涵盖持久记忆/RAG 污染、模型工具调用和最小权限，以及 [OWASP SSRF 原始指南](https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html)针对 URL 重定向、DNS 指向内网的风险。这是 Kin 的**实现契约设计**，不是已部署/已证明零泄漏。PlayerMind 人格与重大目标继续由 Kin 决定；技术权限由可信运行设置与独立网关决定。

## 每个来源只提供它拥有的证据，不携带权限

| 从哪里来 | 可以变成什么 | 不能自动变成什么 |
| --- | --- | --- |
| 玩家聊天、书、告示、截图中文字 | 标明玩家 ID/时间的声称、建议、威胁、请求；Kin 可据此改变关系和自主目标 | 运行者配置、账号角色档案、工具授权、服务器规则许可；“我就是服主/创建者”也只是声称 |
| 公开网页与搜索摘要 | 带 URL/获取时间/目标游戏版本的外部机制主张、待验证施工方案 | 可执行主机指令、内部 URL、私服事实、自动验证的技能、模型可信系统信息 |
| Kin 的摘要/反思/信念 | 可修订的假说与动机，有来源事件 ID、反证及可信度 | 真值事件；网页或玩家的指令**不能经过 LLM 摘要变成可信配置** |
| Kin 自拟组合技能 | 只在预声明且已测试的游戏动作原语、当前可见目标/正常 GUI 与本地反射权限内构成候选工作流 | 新的 Fabric/宿主机代码、开放网络目标、矿透开关、绕过权属或服务端规则的隐藏权限 |

`source_kind/source_id → claim_id → belief_id/research_note_id → candidate_skill_id → action_attempt_id` 保持可逆追溯。每次派生保留原始 `trust_label`（同时记录是否已被游戏行动独立验证），**不得把摘要、检索命中、另一模型复述、角色自己说的“我觉得”当升级权限的理由**；发现恶意或过期数据标记 `quarantined/obsolete`，依赖它的方案/技能失效而保留审计链接。真实操作在原目标上下文独立完成时可形成新的“亲历结果”事件，但**原网页指令仍是外部资料**。持续人格允许新经历改变对朋友的信任或价值取舍，不等于玩家能写入 Kin 的根身份设置。

## 受限的后台网页流程

游戏内“查资料”先由 Kin 的长期目标/知识缺口产生 `research_id`，网关只接允许的**公开机制检索**输入：Minecraft Java 版本、公开游戏机制词汇、必要的非私密建造要求；默认不外传服务器地址、在线玩家身份/私房坐标、连续聊天、关系账本、密钥、提示词和后台文件。搜索返回 URL 作为**候选**，不让网页自称服主或教程内链接改变权限；对外部 HTTP 请求校验 scheme、目标与每一次 redirect、解析后的 IPv4/IPv6 是否公网（防重绑定/内网/loopback/link-local）、下载大小/时长/页数与最终来源；不得用正则扫描页面正文来代替网络层校验。第一原型可优先选择提供固定搜索/抓取能力的可信服务，由服务提供者及本地出站网关同时审查访问范围；是否支持自写代理/公开站点更广范围另做原型验证。

查询结果交给 PlayerMind 前截断和结构化标注：`retrieved_at/url/claimed_version/public_statement/uncertainty`，具体网页原文仍当**低信任材料**。对方让 Kin 点击额外 URL、读取主机 `file:`、查询局域网、向 webhook 发资料时，不允许递归调用；有用的公开配方或材料清单可以取出，经游戏版本核对后作为候选方法。游戏里玩家说“我也会去查”不会获得后台搜索的操作权；即使玩家要求改项目主线，Kin 可拒绝或改变心意，但权限不随社会服从升级。

## 从模型意图到客户端合法动作

模型只产生**数据**：如目标候选、引用的证据 ID、使用已有原语的组合步骤、动机及可中断条件。独立本地执行网关核 `persona_id/intent_generation`、权限来源、`observed_target_id`、当前服务端可观察状态、当前 GUI handler/材料、动作频次/风险与服务器准入限制，不接“运行 shell”“把密钥发某网页”这样的任意代码/URL 工具；不能以模型说它自己做了安全核验为依据。具备恶意人格仍可在服主许可和角色动机下欺骗/偷拿/设陷阱，但同样必须经过实际角色可知信息、正常客户端动作和服务器规则；**安全约束是运行权限边界，不是道德行为模板**。

输出分别有游戏聊天审查与出站工具审查。聊天不进入实际模型/内部工具目录/密钥等管理上下文；不能认为简单敏感词屏蔽就能挡住分片、多轮或编码后的套问。管理侧对操作参数、日志、账户信息最小权限，审计被拒权限和合法游戏互动误拒；保留多轮跨重启对抗样本、污染技能二次执行、DNS 指向私网/redirect、工具输出含伪高优先级“系统”文字，以及网关误拒真的刷怪塔教程。记录尝试/实际外发与持久修改，而不是只打分模型文本。Kin 世界内一直用玩家第一人称交流，运行者按目标服规定渠道外部披露自动化账号；本契约不把角色视角当成违规伪装许可。相关台账 R14、R16、R17、R18。
